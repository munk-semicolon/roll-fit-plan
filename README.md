# My Rolling Workout

I want to create a rolling workout plan system. You would firstly define your different workouts and the amout of time(s) and intevals between e.g. Running 3(thrice) bi-weekly and boxing 1(once) weekly and cycling 1(once) monthly. There will also be a 2 rest days every week. The idea is the the system with all inputs can create a rolling workout plan that within a certain margian fits. The workout plan will vary from week to week depending on the different activites, but will acommidate most of them.
